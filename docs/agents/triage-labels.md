# Triage labels

The five canonical triage roles, used by `/triage` to move issues through the state machine.

| Label | Meaning |
|-------|---------|
| `needs-triage` | Not yet triaged |
| `needs-info` | Blocked on more information |
| `ready-for-agent` | Ready for an agent to pick up |
| `ready-for-human` | Ready for a human to pick up |
| `wontfix` | Will not be worked on |
